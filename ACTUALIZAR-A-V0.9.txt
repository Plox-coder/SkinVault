SKINVAULT REACT v0.9 — NUEVAS COLECCIONES
=========================================

Esta actualización es compatible con SkinVault React v0.8 y con los JSON de
SkinVault Pengu v0.4 (format: 2).

INSTALACION EN WINDOWS (sobre tu proyecto actual)
-------------------------------------------------
1. En tu SkinVault actual pulsa «Copia JSON» para guardar un respaldo.
2. Detén «npm.cmd run dev» en la terminal de VS Code con Ctrl + C.
3. Descomprime este ZIP.
4. Copia los siguientes archivos a la carpeta de tu proyecto actual:

   SkinVault-React/src/App.tsx     ->  TU-PROYECTO/src/App.tsx
   SkinVault-React/src/style.css   ->  TU-PROYECTO/src/style.css
   SkinVault-React/src/i18n.ts     ->  TU-PROYECTO/src/i18n.ts

   Y copia TAMBIEN este archivo nuevo:

   SkinVault-React/public/collection-square-frame.svg
                             ->  TU-PROYECTO/public/collection-square-frame.svg

   Crea la carpeta public si no existe.
5. Arranca con: npm.cmd run dev
6. Abre http://localhost:5173/ y pulsa Ctrl + F5.

PARA QUE APAREZCAN ICONOS, GUARDIANES Y CHROMAS
----------------------------------------------
1. Abre LoL con SkinVault Pengu v0.4 instalado y activado.
2. En Pengu lee iconos, wards y chromas. Si los chromas figuran como
   «por verificar», pulsa las tandas de escaneo que necesites.
3. Pulsa «Exportar JSON» en Pengu.
4. En la WEB pulsa «Importar colección» y elige ese nuevo JSON.
5. Aparecerán las pestañas Skins, Iconos, Guardianes, Chromas.

IMPORTANTE
----------
- Los marcos cuadrados de iconos y guardianes están dibujados a partir del
  estilo de la colección de LoL; no son todavía una copia exacta del recurso.
- Las imágenes se cargan de CommunityDragon / Data Dragon y necesitan Internet.
- «Por verificar» significa que Pengu no ha confirmado si posees el objeto.
  No cuenta como faltante. Puedes marcarlo manualmente si lo sabes.
- Los precios RP solamente se suman para las skins; no se asignan precios
  inventados a los demás objetos.
- Se mantiene el guardado en localStorage de la versión anterior.
- La aplicación no lee automáticamente el cliente: importa el JSON de Pengu.

ARCHIVOS DEL PROYECTO
---------------------
También puedes ejecutar este proyecto completo como un proyecto independiente
con npm.cmd install y npm.cmd run dev, pero si quieres conservar los datos
locales de tu instalación, actualiza los archivos dentro del proyecto que ya usas.
